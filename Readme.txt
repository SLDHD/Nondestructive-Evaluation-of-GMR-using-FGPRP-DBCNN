FGPRP-attention-enhanced DBCNN: Fault Diagnosis Framework for Giant Magnetostrictive Rods

This repository provides the implementation of the FGPRP-attention-enhanced DBCNN framework proposed for weak fault diagnosis of giant magnetostrictive rods (GMRs).

The framework integrates:
1. Fuzzy Granular Probabilistic Recurrence Plot (FGPRP) for vibration signal-to-image transformation.
2. Attention-enhanced Dual-Branch Convolutional Neural Network (DBCNN) for fault classification.

The complete workflow converts one-dimensional vibration signals into two-dimensional image representations and performs multi-condition fault diagnosis using a unified deep learning classifier.

3. Overall Workflow

Stage 1: Signal preprocessing and image generation

Script:
main.m

Functions:
- Load raw GMR vibration signals.
- Segment continuous signals into fixed-length windows.
- Generate image samples using FGPRP.

The default segmentation parameters follow the manuscript:
- Window length: 256 samples.



Stage 2: FGPRP feature extraction

Function:
FGPRP.m

Functions:
- Transform one-dimensional vibration windows into two-dimensional recurrence representations.
- Perform fuzzy granulation.
- Calculate probabilistic recurrence intensity using Gaussian kernel mapping.

Input:
- 1-D vibration signal window

Output:
- 2-D FGPRP image


Stage 3: Fault classification

Script:
attention-enhanced_DBCNN.py

Functions:
- Train and evaluate the attention-enhanced DBCNN classifier.
- Perform fault classification using generated image samples.

The classifier includes:
- dual-branch convolutional architecture;
- CBAM attention modules;
- bidirectional cross-attention feature interaction;
- feature fusion and fully connected classification layers.

Training configuration:
- Optimizer: Adam
- Learning rate scheduler: StepLR
- Weight decay: 1e-4
- Batch size: 32
- Training epochs: 20


4. Reproducing Experimental Results

4.1 Image Generation

Run:

main.m

This step generates FGPRP image datasets from vibration signals.


4.2 Classification Results

Run:

attention-enhanced_DBCNN.py

This script performs:
- dataset loading;
- model training;
- validation;
- testing;
- accuracy calculation.

Example:

python attention-enhanced_DBCNN.py --seed 1 --snr -5

Parameters:
- --seed: random initialization seed.
- --snr: Gaussian noise level.

5. Script-to-Manuscript Correspondence

main.m:
Signal segmentation and FGPRP image generation.
Corresponds to image generation procedure.

FGPRP.m:
Proposed FGPRP feature extraction algorithm.
Corresponds to FGPRP image representation.

Attention-enhanced DBCNN.py:
Attention-enhanced DBCNN training and evaluation.
Corresponds to main classification experiments.

run_five_seeds.py:
Repeated training with different random seeds.
run_five_seeds.py reproduces the five-seed evaluation for a specified SNR level. To reproduce Tables 5–10, execute this script for SNR values from -5 dB to 5 dB.
